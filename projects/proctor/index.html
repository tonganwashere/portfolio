Proctor

Terminal-based examination, quiz, and question bank management platform built in Java with MVC architecture, PostgreSQL persistence, and built-in AI for assessment generation and grading.

Java Terminal UI PostgreSQL Ollama MVC

About

Proctor is a terminal user interface (TUI) examination, quiz, and question bank management platform built in Java. Built as a comprehensive assessment tool, it runs in the command line and provides an intuitive, navigable environment for both teachers and students.

The platform features multiple assessment modes such as quizzes, exams, and speed quizzes. Teachers can build and organize question banks, create custom multiple-choice, true/false or short-answer questions. Students can take assessments with real-time prompt feedback, timed modes, and instant score summaries.

Proctor also includes local AI integration via Ollama running Llama 3.2. Teachers can use AI to automatically generate questions and answer choices from custom prompts or study topics, and students receive AI-assisted grading and correction for submissions.

All data is stored in PostgreSQL and the app features an automated schema manager that validates, creates, and migrates database tables and constraints upon first startup.

This was developed as a collaborative group project where I took full ownership of the implementation, building the complete architecture, features, and database layers solo over two months.
