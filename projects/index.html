Flip Decibel

2026 · Android · Finished

Java · Android · OpenGL ES 2.0

An Android coin-flip app with a 3D coin rendered in OpenGL ES 2.0. The coin has adjustable flip speed and a full skin system, custom labels, images, or animal skins on each side. There's also a hidden Rig Mode that silently ties the result to your phone's volume, so you always get the side you want. My first Android app and first time working with OpenGL, built solo over two months.

PyDFile

2026 · Windows · Finished

Python · CustomTkinter · PyMuPDF · pikepdf · PyInstaller

A local-first desktop PDF tool built in Python. Covers merging, splitting, page reordering, compression, watermarking, page numbering, password protection, unlocking, image conversion, and text extraction. Works completely offline and is packaged as a standalone Windows executable via PyInstaller so there's no Python install required to run it.

Genera

2026 · Web · Actively maintained

Python · Flask · JavaScript · SQLite · IndexedDB · Service Worker

An offline-first flashcard web app built with vanilla JavaScript, Flask, and SQLite. Comes loaded with 4,500+ trivia questions across 24 categories and uses a 5-box Leitner spaced repetition system. Works offline through IndexedDB and a service worker, and syncs cards and review progress across devices with account-based conflict resolution. Built solo in about a month.
