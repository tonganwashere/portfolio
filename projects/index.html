Genera

Oct 2026 · Web · Actively maintained
Python Flask JavaScript SQLite IndexedDB Service Worker

A flashcard web app built with vanilla JavaScript, Flask, and SQLite. It works offline and comes loaded with 4,500+ trivia questions across 24 categories and uses a 5-box Leitner spaced repetition system. It also works offline through IndexedDB and a service worker, and syncs cards and review progress across devices with account-based conflict resolution. This project was built solo in about a month.

PyDFile

A local desktop PDF tool built in Python that covers merging, splitting, page reordering, compression, watermarking, page numbering, password protection, unlocking, image conversion, and text extraction all in one lightweight app. It works completely offline and is packaged as a standalone Windows executable via PyInstaller so Python isn't required to run it. Flip Decibel

May–Jun 2026 · Android · Finished
Java Android OpenGL ES 2.0

An Android coin flip app with a 3D coin rendered in OpenGL ES 2.0. The coin has adjustable flip speed and a full skin system along with custom labels or images. There's also a hidden Rig Mode that silently ties the result to your phone's volume, so you always get the side you want. This is my first Android app and first time ever working with OpenGL. This project was built solo over the course of 2 months.
