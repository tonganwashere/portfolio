Wordle++

Terminal-based word guessing game written in C++. 4 game modes, player accounts, a leaderboard, and a built-in admin panel, all running in the command line.

C++ FTXUI nlohmann/json CMake

About

Wordle++ is a terminal based word guessing game written in C++, based on the original Wordle by the New York Times. It runs entirely in the command line via a CMake build with no GUI, no browser, and no external setup beyond building the project. The interface is handled by FTXUI, which gives the game a proper terminal UI with color-coded tile states, real-time keyboard input, and navigable menus.

The game has 4 modes: 3-letter, 5-letter, 6-letter, and a daily challenge. Players can sign up for an account and their stats (wins and current streak) are tracked on a persistent leaderboard. Word banks are stored as separate JSON files per mode using nlohmann/json, and can be edited directly in the files or managed through the game itself.

The built-in Admin Mode is accessible by logging in with username "admin" and password "admin123". From there you get 2 panels: one for adding or removing words from any word bank, and one for deleting player accounts. It was designed so the game could be managed at runtime without anyone needing to open a file manually.

Every line of code was written solo over about a month. Feature ideas and direction came from the team, but the implementation was all mine.
