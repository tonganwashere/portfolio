# Portfolio

My personal portfolio website, designed and built from scratch with semantic HTML, Tailwind CSS, and vanilla JavaScript. 

Live at [tongan.dev](https://tongan.dev)

## Featured Projects

- **[Genera](https://tongan.dev/projects/genera/):** Offline-first flashcard web app built with vanilla JS, Flask, and SQLite using a 5-box Leitner spaced repetition system, IndexedDB, and cross-device sync.
- **[Proctor](https://tongan.dev/projects/proctor/):** Terminal-based exam and quiz platform built in Java with MVC architecture, PostgreSQL, and AI grading via Ollama.
- **[PyDFile](https://tongan.dev/projects/pydfile/):** Offline, local-first desktop PDF utility built in Python and packaged with PyInstaller for Windows.
- **[Pitch Flip](https://tongan.dev/projects/pitch_flip/):** Android coin-flip app built with Kotlin, rendered in 3D using OpenGL ES 2.0 with custom skins and a hidden volume-rigged mode.
- **[Wordle++](https://tongan.dev/projects/wordlepp/):** Terminal-based Wordle clone built in C++ with FTXUI, accounts, leaderboards, and an admin panel.

## Built With

- **Markup & Styling:** Semantic HTML5, Tailwind CSS, Inter font
- **Interactivity:** Vanilla JavaScript (light/dark mode toggle, fullscreen media viewer)
- **Assets & Icons:** Lucide SVG icons, custom Open Graph social preview cards
- **Deployment:** GitHub Pages with custom domain (`tongan.dev`)

## Pages

- `index.html` - Home overview with bio, featured projects, and skills
- `projects/` - Full project archive and individual project detail pages
- `about/` - Background, education, and photo highlights
- `cv/` - Curriculum vitae view and downloadable PDF
